# 给 Qoder 的建站指令（复制这段喂给 Qoder Sites）

> 用法：在 Qoder 里新建 task，把下面整段粘进去。
> 先让它出预览，确认交互对了再发布。**发布后记得把访问范围改成 Anyone can access。**

---

做一个「野外地调资料检索」网站，给我和同组同学用。

**背景**：野外踩点后会留下大量零散记录（剖面、采样点、观测点、露营地），
按文件名和文件夹根本找不回来。这个站点要解决的问题是——
用一句话描述需求，直接捞出最相关的点位。

**核心交互**

1. 顶部一个搜索框，输入自然语言，例如：
   - 「附近有水源的露营地」
   - 「适合观测的剖面」
   - 「能扎帐篷、车能开到的地方」
2. 搜索框下方两个筛选：
   - 半径下拉：1 / 3 / 6 / 10 km，默认 6
   - 复选框「使用我的位置」，勾上时以固定示例坐标（30.521, 114.402）为圆心
3. 结果以卡片列表展示，每张卡包含：
   - 点位名称 + 类型标签（剖面 / 采样点 / 观测点 / 露营地）
   - 采集日期、海拔、坐标
   - **距离（km）**，加粗
   - 现场记录原文
   - 一行小字说明「为什么它排在这里」，例如「命中关键词 水源 · 距离 2.43 km」
4. 空结果时显示友好提示，不要显示空白页或报错堆栈。

**数据结构**（后端 `/api/search` 已实现，返回这个形状）

```json
{
  "items": [
    {
      "id": 3,
      "name": "磨山南麓露营地",
      "kind": "露营地",
      "lat": 30.538,
      "lon": 114.418,
      "collected_at": "2026-09-14",
      "elevation_m": 76,
      "note": "林地空地，地面平整可扎两顶帐篷，附近有水源但需煮沸",
      "dist_km": 2.43,
      "kw_hit": 1,
      "reason": "命中关键词 水源 · 距离 2.43 km"
    }
  ],
  "total": 1
}
```

接口：`GET /api/search?q=水源&lat=30.521&lon=114.402&max_km=6&topk=6`

**视觉要求**

- 浅色、干净，白色卡片 + 浅灰背景，不要花哨渐变色
- 中文字体优先用系统字体
- 桌面两列、移动端单列
- 距离数字要显眼，这是用户判断的第一依据

**必须写进页脚的一句话**

> 线上演示使用内置示例数据；完整 seekdb 检索请按仓库 README 在本地启动。

**不要做的事**

- 不要加地图组件（会增加依赖，且示例坐标不需要展示在地图上）
- 不要加登录、用户系统
- 不要用 Vue / React 之外的额外 UI 库，保持零外链

**先出预览，不要发布。** 我确认交互之后，再让你发布并配置公开访问。

## 发布之后

1. 站点右上角 **Publish** → 等状态变 **Published**
2. 详情里拿地址，**自己先用无痕窗口打开一次**
3. **Share → Change access scope → Anyone can access**，确认 **Allow public access**

第 2 步和第 3 步顺序不要反：先确认默认私有状态下能打开，再放开权限，
这样出问题时能分清是"没发布成功"还是"权限没配对"。
